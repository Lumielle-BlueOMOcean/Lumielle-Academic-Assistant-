# User manual sources

The editable Chinese and English manuals are `使用手册（必读）.docx` and `User_Guide_EN.docx` in this directory. The restored poster is maintained at `../assets/lumielle_poster.png`.

The next complete manual revision should include the new “Test Model Connection” step in the LLM configuration workflow. / 下一版完整手册需要纳入 LLM 配置中的“测试模型连接”步骤。

Edit the DOCX sources and export them to the existing repository PDF names in `docs/` with a document-flow layout engine such as LibreOffice. Keep the poster on its own page immediately before the version history. Do not generate section-per-page PDFs.

For every export, render every page to images, make a full-manual contact sheet, and inspect both the sheet and each page at readable resolution. Check pagination, text rendering, poster placement/caption, page numbers, and the version history before replacing the canonical PDFs.
